# Brazilian School Dropout Prediction: End-to-End Data Pipeline

This repository contains a comprehensive data project focused on predicting school dropout rates in Brazil using large-scale public datasets. While the core objective is predictive modeling, the project addresses significant **Data Engineering** challenges inherent in processing fragmented and noisy government data.

## 🚀 Engineering Highlights

* **Data Wrangling at Scale:** Handled diverse datasets from Brazilian government sources (INEP), implementing robust cleaning pipelines to manage missing values, inconsistent encodings, and structural changes across different census years.
* **Feature Engineering Pipeline:** Developed a modular preprocessing flow to transform raw socio-economic indicators into high-signal features for Machine Learning, ensuring data integrity and reproducibility.
* **Scalable Architecture:** Designed the logic with a focus on modularity, allowing for the integration of new data sources (state or municipal levels) with minimal refactoring.

## 🛠️ Tech Stack

* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn (Preprocessing & Modeling)
* **Concepts:** ETL, Feature Engineering, Statistical Validation, Exploratory Data Analysis (EDA).

## 📈 Key Outcomes

* Successfully integrated multiple public data sources into a unified, analysis-ready data asset.
* Identified critical socio-economic risk factors through rigorous data auditing and statistical hypothesis testing.
* Built a predictive framework that serves as a prototype for data-driven public policy intervention.
